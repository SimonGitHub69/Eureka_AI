L'assistente vocale (icona microfono) usa prima i comandi configurati qui, poi i comportamenti predefiniti. Puoi abilitarlo o disabilitarlo globalmente in Parametri programma.

  • Apri pagina — naviga alla sezione scelta (es. frase apri clienti)
  • Cerca — apre l'elenco con filtro ?q= e, dove supportato, stato=attivi (solo record attivi); se la query è vuota usa il testo dopo la frase (es. cerca cliente Rossi → q=Rossi&stato=attivi)
  • Modalità di match — Contiene, Esatto o Inizia con sul testo normalizzato (minuscolo, senza accenti)
